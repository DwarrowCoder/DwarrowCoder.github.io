The Rise of House Montagna

Character Creation

Here is a quick reference of the process to create a character for this campaign.

Creation Steps

  1. Concept: Consider your character idea. Select a faction template if applicable and record its trait if you do.
  2. Archetype: Choose or adapt an archetype from the list. Record its trait.
  3. Select Region (Optional)
  4. Select Deity/Faith
  5. Select Class
  6. Select Starting Feat
  7. Select Starting Equipment
  8. Select Background Traits

Step 8: Select Background Traits

Choose two traits, plus one if you select a drawback, from the following categories: Basic - Combat, Basic - Faith, Basic - Magic, Basic - Social, Race, Regional, and Religion. Traits should be tied to your backstory in some way and are subject to DM approval. All traits should be from different categories.
